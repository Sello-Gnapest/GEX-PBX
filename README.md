# GEX PBX Enterprise OS

**GEX PBX** (Global Extension Exchange) is a modern, high-tech WebRTC softphone and cloud IP PBX switchboard platform. Built for enterprise telecommunications and regional operations, it delivers seamless dual-ring mobile twinning, real-time BLF extension monitoring, native device contact integration, and full South African telecom provider routing (Telkom SA, Vodacom, MTN, and Telkom Mobile).

---

## Key Features

* **Operator Switchboard Console**: Full multi-line call handling, active call status telemetry, quick dialing, and single-click call transfers.
* **Mobile SIM Twinning & Linking**: Connect standard cellular numbers (e.g., Vodacom, MTN) directly to internal extensions with *Simultaneous Dual-Ring*, *Follow-Me Routing (15s delay)*, or *Unconditional Diverting*.
* **Outbound Caller ID Masking**: Seamlessly switch between presenting your corporate Durban pilot line (`031 940 8800`) and direct cellular numbers when placing calls.
* **Unified Phonebook & vCard Import**:
* **Native Device Contact Picker**: Integrates with the W3C Contact Picker API (`navigator.contacts`) for 1-tap contact imports on mobile and supported desktop browsers.
* **Universal vCard Support**: Drag-and-drop `.vcf` file parsing for instant contact synchronization across iOS, Android, and Desktop.
* **Predictive Dialpad Matching**: Real-time contact matching as agents enter digits or names.


* **BLF Extension Matrix**: Live Busy Lamp Field (BLF) status monitoring across regional office extensions.
* **WebRTC Softphone & Provisioning**: Browser-based softphone with high-definition audio, OLED dialer display, and automated DHCP Option 66 hardware provisioning templates.
